# Glossary

- **Hold** — a temporary 10-minute reservation on a ticket, created when a user clicks "Get Ticket"
- **Payout** — the automatic transfer of an organizer's share (95%) of a completed sale
- **Webhook** — an HTTP callback IntaSend sends to confirm payment or payout status changes
- **Room** — a Socket.io channel (event:{id}, user:{id}, admin-room) used to broadcast live updates
- **Sweep** — the background job that expires stale holds every 5 minutes
