# Environment Variables Reference

## Backend
- DATABASE_URL — PostgreSQL connection string
- JWT_SECRET — signing key for auth tokens
- FRONTEND_URL — allowed CORS origin
- INTASEND_PUBLISHABLE_KEY / INTASEND_SECRET_KEY — payment collection
- INTASEND_WEBHOOK_CHALLENGE — webhook verification string
- GOOGLE_CLIENT_ID — OAuth verification
- RESEND_API_KEY — password reset emails

## Frontend
- NEXT_PUBLIC_API_URL — backend base URL
- NEXT_PUBLIC_GOOGLE_CLIENT_ID — OAuth client for Google button
